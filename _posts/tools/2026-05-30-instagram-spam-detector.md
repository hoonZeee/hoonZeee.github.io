## 이런 댓글 본 적 있으신가요?

```
성 세 라 G 컵 gⓞⓞgⓛe 검 색 ㄹㅈㄷ 미 드 지 림
[성세라 원 본] 구 글 검 색 하면 VIP 전용 방 송 사 고나옴
>성 세 라 사 건< ġ૦૦ġĿ 검 색 미 드 지 림
```

인기 게시물에 댓글 알바들이 이런 식으로 수백 개씩 달아놓습니다.  
글자 사이에 공백을 넣거나 이상한 기호를 섞어서 인스타그램 자체 필터를 일부러 피하는 방식이에요.

하나씩 손으로 지우는 건 현실적으로 불가능하죠. 😔
---

## 이 앱이 뭔가요?

직접 만든 **무료 Windows 앱**입니다.

- 내 게시물에 달린 댓글을 자동으로 수집해서
- 스팸·알바 댓글을 골라내고
- 선택한 것들을 한 번에 삭제해드려요

비밀번호를 입력받거나 저장하지 않습니다.  
브라우저에서 직접 로그인하시고, 앱은 그 세션만 사용해요.

## 사용 방법

### 1단계 — 앱 실행 후 로그인

앱을 실행하면 Chromium 브라우저가 열립니다.  
그 브라우저에서 본인 인스타그램 계정으로 직접 로그인해 주세요.

한 번 로그인하면 다음에는 자동으로 유지됩니다.

---

### 2단계 — 게시물 선택

1. 내 인스타 아이디를 입력하고 **"내 게시물 페이지로 이동"** 버튼 클릭
2. 브라우저에서 댓글을 정리하고 싶은 게시물 클릭
3. 앱의 **"이 게시물 선택"** 버튼 클릭
4. 확인 카드가 나오면 맞는지 확인하고 **"댓글 불러오기"**

---

### 3단계 — 탐지 결과 확인

댓글이 자동으로 위험도별로 분류됩니다.

| 탭 | 내용 |
|----|------|
| 🔴 높음 | 거의 확실한 스팸 — 기본으로 체크됩니다 |
| 🟠 중간 | 의심스러운 댓글 — 기본으로 체크됩니다 |
| 🟡 검토 | 애매한 댓글 — 직접 확인이 필요해요 |
| 🔍 검색 | 원하는 단어로 직접 검색 |
| 💬 전체 댓글 | 수집된 댓글 전부 보기 |

---

### 4단계 — 삭제

체크된 댓글을 확인하신 뒤 **"선택 삭제"** 버튼을 누르시면 됩니다.

필터가 놓친 댓글이 있다면 🔍 **검색 탭**에서 의심 단어를 직접 입력해 보세요.  
그 단어가 포함된 댓글과 비슷한 변형 댓글까지 한꺼번에 찾아드립니다.
